## 1. FM2.2-03 — หลักฐานการเบิกจ่ายเงินค่าสอนพิเศษและค่าสอนเกินภาระงานสอน

### ส่วนหัว

| ช่องในแบบฟอร์ม | ที่มาของข้อมูล | หมายเหตุ |
|---|---|---|
| ส่วนราชการ | `app_settings['org.name']` | คงที่ ไม่ให้แก้รายเอกสาร |
| คณะ | `payment_vouchers.faculty_text` | เติมค่าเริ่มต้นจาก `course_offerings.faculty_text` |
| ภาคการศึกษา | `payment_vouchers.semester_text` | เติมจาก `semesters.name_th` |
| พ.ศ. | `payment_vouchers.year_be` | แปลงจาก `academic_years.year_be` |
| วิชา | `payment_vouchers.subject_text` | เติมจาก `courses.code + name_th` |

> เก็บเป็นข้อความ **snapshot** ไม่ใช่ join สด เพราะเอกสารที่พิมพ์ส่งฎีกาแล้วต้องไม่เปลี่ยนตามการแก้ชื่อวิชาในภายหลัง แต่ใส่ค่าเริ่มต้นให้อัตโนมัติจากฐานข้อมูลตามข้อกำหนด (dropdown)

### ข้อสังเกตจากคำอธิบายการกรอก

**ข้อ (6) ที่ต้องระวัง** — คำอธิบายระบุให้ทำเครื่องหมาย ✓ ในช่อง "ผู้ได้รับเชิญให้สอน" เฉพาะกรณีผู้ได้รับเชิญตามข้อ 14.3 ที่ **มิได้** เป็นข้าราชการหรือลูกจ้างของทางราชการ หรือพนักงาน/ลูกจ้างของรัฐวิสาหกิจ

นั่นคือช่องนี้ติ๊กเมื่อสถานะ "ไม่ใช่" ข้าราชการ ซึ่งตรงข้ามกับสัญชาตญาณ จึงเก็บข้อมูลผู้รับเงินเป็น `payees.is_government_officer` (ตรงไปตรงมา ผู้กรอกเข้าใจง่าย) แล้วให้ UI เสนอค่า `is_invited_external = NOT is_government_officer` เป็นค่าเริ่มต้น แต่ยังแก้รายบรรทัดได้ ควรมีข้อความกำกับใต้ช่องติ๊กในหน้าจอเพื่อกันการกรอกผิด

**ข้อความท้ายคำอธิบาย** — "ให้เจ้าหน้าที่ทำการเบิกจ่ายเงินค่าสอนพิเศษและค่าสอนเกินภาระงานสอน **ภาคละ 1 ครั้ง**"
ระบบจึงควรเตือน (ไม่ใช่ห้าม) เมื่อสร้างใบหลักฐานใบที่สองสำหรับ `course_offering` เดียวกันในภาคเดียวกัน เพราะในทางปฏิบัติอาจมีการเบิกเพิ่มเติมหรือแก้ไข แต่ควรบังคับให้ระบุเหตุผล

### จุดที่ต้องแก้จากต้นฉบับ

**ชื่อผู้อำนวยการถูกพิมพ์ตายอยู่ในไฟล์ PDF ต้นฉบับ** ("ผู้ช่วยศาสตราจารย์พนารัตน์ วิศวเทพนิมิตร")
ถ้าฝังไว้ในโค้ด เมื่อเปลี่ยนผู้บริหารจะต้องแก้โปรแกรมและ deploy ใหม่ ระบบนี้จึงดึงจาก `app_settings['org.director']` แทน — **ยังไม่ได้เติมค่า กรุณาแจ้งคำนำหน้า ชื่อ-สกุล และตำแหน่งที่ถูกต้อง ณ ปัจจุบัน**

**การกันเบิกซ้ำ** — ตาราง `treasury_cover_sheet_items` มี `UNIQUE (voucher_id)` ทั่วทั้งตาราง แปลว่าใบสำคัญ 1 ใบ ขึ้นหน้างบได้เพียงครั้งเดียวในทั้งระบบ นี่เป็นการควบคุมภายในขั้นพื้นฐานที่หน่วยตรวจสอบมักถามหา

## 3. ข้อกำหนดกับแบบฟอร์มที่ไม่ตรงกัน

ข้อกำหนดระบุว่าตารางสรุปการจ่ายเงินบนแดชบอร์ดต้องแสดงรายการ:

> ค่าสอนทฤษฎี/ทดลอง, **ค่าสอนปฏิบัติ**, **ค่าตอบแทนแหล่งฝึก**, **ค่าเดินทางไปนิเทศ**, **ค่าตอบแทนผู้ป่วยเสมือน**

แต่แบบ FM2.2-03 มีเพียงคอลัมน์ "จำนวนหน่วยชั่วโมงที่ทำการสอนพิเศษและสอนเกินภาระงานสอน" กับ "จำนวนเงิน" เท่านั้น **ไม่มีช่องแยกประเภทค่าใช้จ่ายทั้งสี่รายการข้างต้น**

การออกแบบจึงแยกสองชั้น:

- **ฐานข้อมูล** เก็บ `expense_item` ครบทั้ง 6 ประเภท เพื่อให้แดชบอร์ดและการควบคุมวงเงินทำงานได้ถูกต้อง
- **การพิมพ์แบบ FM2.2-03** ใช้ได้กับทุกประเภท เพราะวิทยาลัยยืนยันว่าใช้แบบฟอร์มเดียวกันทั้งของอาจารย์พิเศษและของแหล่งฝึก (ดูการแม็ปช่องในข้อ 4)

## 4. ใบหลักฐานฯ ของแหล่งฝึก — ใช้แบบฟอร์มเดียวกัน

**ยืนยันจากวิทยาลัยแล้ว:** ใบหลักฐานการเบิกจ่ายของแหล่งฝึกใช้แบบ **FM2.2-03 ฉบับเดียวกัน**
กับของอาจารย์พิเศษ ไม่มีแบบฟอร์มแยก

ฐานข้อมูลรองรับแล้วผ่าน `payment_vouchers.voucher_kind` และ `voucher_lines.clinical_site_id`
การพิมพ์ใช้เทมเพลตเดียวกัน โดยแม็ปช่องดังนี้เมื่อผู้รับเงินเป็นแหล่งฝึก

| ช่องในแบบฟอร์ม | เมื่อผู้รับเงินเป็นบุคคล | เมื่อผู้รับเงินเป็นแหล่งฝึก |
|---|---|---|
| ชื่อ – นามสกุล | `payees.prefix/first_name/last_name` | `clinical_sites.name_th` + Ward ถ้ามี |
| ตำแหน่งผู้ทำการสอน | `payees.position_title` | ชื่อหมวดรายการ เช่น "ค่าตอบแทนแหล่งฝึก" |
| ผู้ได้รับเชิญให้สอน (✓) | ตาม `is_invited_external` | ติ๊ก (แหล่งฝึกไม่ใช่ข้าราชการของวิทยาลัย) |
| ระดับการสอน | ตาม `teaching_level` | ปริญญาตรี (ตามหลักสูตรที่ส่งนักศึกษาไปฝึก) |
| จำนวนหน่วยชั่วโมง | ชั่วโมงสอน | ปล่อยว่างสำหรับค่าตอบแทนเหมาจ่าย หรือใส่จำนวนหน่วยตามที่คิดจริง |
| ลายมือชื่อผู้รับเงิน | ผู้สอนลงนาม | ผู้มีอำนาจของแหล่งฝึกลงนาม |

**สามข้อที่ต้องยืนยันกับงานการเงินก่อนพิมพ์ใช้จริง** เพราะเป็นการนำแบบฟอร์มค่าสอน
ไปใช้กับรายการที่ไม่ใช่ค่าสอนรายชั่วโมง ซึ่งผู้ตรวจสอบอาจตั้งคำถาม

1. ช่อง "ตำแหน่งผู้ทำการสอน" ของแหล่งฝึก ปัจจุบันเขียนว่าอะไร
2. ค่าเดินทางไปนิเทศและค่าตอบแทนผู้ป่วยเสมือน ลงในใบเดียวกับค่าตอบแทนแหล่งฝึก
   หรือแยกใบ (ระบบรองรับทั้งสองแบบ แต่ต้องเลือกให้ตรงกับที่ทำอยู่)
3. ช่อง "จำนวนหน่วยชั่วโมง" ของรายการเหมาจ่าย เว้นว่างหรือใส่ตัวเลข

## 5. คำถามที่ยังต้องตอบก่อนทำหน้าพิมพ์เอกสาร

1. **"คณะ" บนแบบฟอร์ม** วิทยาลัยกรอกอะไรในช่องนี้ — ชื่อสาขาวิชา ชื่อหลักสูตร หรือเว้นว่าง
2. **ระดับการสอน** วิทยาลัยมีหลักสูตรระดับบัณฑิตศึกษาหรือไม่ ถ้าไม่มี ช่องนี้ตั้งค่าตายเป็น "ปริญญาตรี" ได้เลย
3. **หน้างบฯ ช่อง "ระดับ: ต่ำกว่าปริญญาตรี"** ยังใช้อยู่หรือไม่
4. **ผู้รับรอง** บนแบบ FM2.2-03 ระบุ "อาจารย์ประจำชั้น" — ควรดึงจากฐานข้อมูลผู้ประสานงานรายวิชา หรือพิมพ์เองทุกครั้ง
5. **อัตราค่าตอบแทน** ปัจจุบันกรอกจำนวนเงินเองทุกบรรทัด หรือควรให้ระบบคำนวณจาก ชั่วโมง × อัตราตามหมวดเงิน (ถ้ามีตารางอัตราให้ จะเพิ่มตาราง `pay_rates` และคำนวณอัตโนมัติพร้อมกันเบิกผิดอัตรา)
